# Morocco elections 2011–2021 · dashboard (Darija)

Interactive dashboard of the 2011, 2016 and 2021 legislative elections in Morocco:
how votes turn into seats, and seats into government.

**Open it:** https://leonafricanus.github.io/morocco-elections/

One self-contained HTML file (`index.html`), no build step.

## Sources
- Election results: TAFRA (openAfrica)
- Population: HCP general census 2014
- Survey: Arab Barometer waves III, IV and VII (unweighted)
- Province boundaries: geoBoundaries (OpenStreetMap contributors, ODbL)
- Government lists: hand-coded

Computed with the *Morocco Elections KPI Toolkit* notebook. The Darija text still needs a native review.
